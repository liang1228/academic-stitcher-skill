## I — 方法论骨架 (Interpretation)

1. 先把“这个方向值得做吗”改写成一张可核对的可行性卡，而不是凭兴趣或热度下结论。
2. 用近两三年文献活跃度、可检索综述、组内可交接知识与资源三条证据通道，分别记录强、弱、缺失或待核验。
3. 三个信号是风险证据，不是必须全部为正的机械准入表；新兴方向可以用开源基准和活跃社区作为替代证据，先做限时试点。
4. 方向初筛后，再用综述建立任务、方法、数据、指标和演化路线地图。
5. 把缺口拆成通用理论、专业理论、实验技能、数据与设备，并为每项缺口安排动作和验收物。
6. 数据资源要单独过硬门：公共不等于无许可或无偏差，私有也不等于更有效；两者都要核对授权、版本、匹配、处理和交付。
7. 先做最小合法复现，再决定继续、缩题或换题；没有可运行入口就保持“待核验”，不能用漂亮题目替代证据。
8. 输出必须保留来源、状态、不确定性和停止条件，不能把个人经验、旧年份判断或课程修辞升级为普遍规则。

## A1 — 书中的应用 (Past Application)

### 案例 1：交接意愿作为资源信号（课程转述示例）

- **问题**：组会上有学生想沿用课题组方向，但师兄师姐都明确不愿意带，他仍继续追问。
- **方法论的使用**：把“有人名义上做过这个方向”与“有人愿意且能够交接代码、数据和隐性知识”分开；将实际交接意愿作为第三个可行性信号，而不是把课题组经历自动记成资源。
- **结论**：明确不愿交接是资源与传承信号的负面证据，应先停止把该方向当作已有传承入口；它不单独证明方向本身一定不可做。
- **结果**：课程没有交代该学生后续是否成功；能确认的结果只有“交接意愿不足”这一风险信号。
- **证据状态**：课程中出现的讲者转述示例；候选 `c02`，`01-03 00:03:00.020–00:03:59.980`；ASR 待音频复核。不是作者个人成功经验，也不升级为普遍定律。

### 案例 2：Fluent、机器学习与 Python 的跨领域路线（学生问题示例）

- **问题**：学生描述相关文献较少、导师指导有限，难以找到清晰的研究入口。
- **方法论的使用**：把 Fluent 工况模拟、机器学习和 Python 拟合串成一条可以先做最小验证的候选路线，先检查是否能形成可运行任务，再谈创新或论文价值。
- **结论**：该路线可作为可行性试点的构想，不应因“看起来能做出结果”就直接锁定为学位主线。
- **结果**：语料没有展示实验完成、投稿或结果复核；只能记录为候选路线，不能声称它已经有效。
- **证据状态**：补充候选 `sc06`；BVID `BV1mxoFB9Ekw`，语料块 `block-033.md`，`00:05:41.350–00:06:16.430`；AI 字幕待音频复核。属于课程中的学生示例，不是已验证成果。

### 案例 3：讲者现场从无人机检测论文池构造开题候选

- **问题**：讲者现场面对自己尚不熟悉的无人机小目标检测任务，需要把一个热门任务收窄成可讨论的研究入口。
- **方法论的使用**：检索论文并抽取任务对象、已有网络和可组合模块，先生成候选题目，再把它标为假设，保留后续实现和实验验证门。
- **结论**：论文池可以帮助形成候选方向和初步地图，但候选题名不等于方向可行、方法有效或创新成立。
- **结果**：现场生成了一个候选题目；课程没有给出实现与实验结果，因此只能确认候选生成，不补写研究成败。
- **证据状态**：课程现场示例（example），属于讲者当场演示而非已完成研究的成果自述；候选 `c03`，视频 01-05 00:13:00.240–00:15:59.980；ASR 待音频复核。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户已有一个或多个研究大方向，正在比较“近年热门、冷门但有资源、跨领域但缺传承”哪条路线更可能做得动，并需要继续、缩小或换题的依据。
2. 用户方向已经大致确定，却不知道应先补通用理论、专业理论、实验技能，还是先解决数据、设备、算力和组内交接，并希望得到一张有验收动作的基础缺口地图。
3. 用户面对没有正式综述或组内传承的新兴方向，但手上有开源基准、公开代码或活跃社区，想判断能否用限时最小复现试点替代机械放弃。

### 语言信号 (用户的话里出现这些就应激活)

- 中文：“这个研究方向到底能不能做、要不要换题？” / English: “Is this research direction feasible, or should I pivot?”
- 中文：“我现在缺哪些理论、实验、数据或设备基础？” / English: “What foundation gaps or prerequisites do I need to close?”
- 中文：“没有综述、组里也没人做，但有开源基线，能不能先试点？” / English: “There is no survey or lab handoff; should I run a time-boxed feasibility pilot?”

### 与相邻 skill 的区分（阶段 3/4 定稿）

- 与 `u01`《目标约束逆推研究路径》的区别：`u01` 先处理毕业/就业/深造目标、导师顺序和总体硬约束；本单元假定已有大方向，进一步检查该方向的文献生态、传承、资源和基础缺口。
- 与 `u04`《目的驱动的四入口论文拆解》的区别：`u04` 针对已经找到的论文，产出摘要/引言/方法/实验的组件证据图；本单元判断是否值得进入一个方向，不替代单篇论文拆解。
- 与 `u06`《基准模型可复现闸门》及 `u08`《组合研究实验闭环》的区别：`u06/u08` 面向已选定的基线或组合，做正式复现、对比、消融和归因；本单元只把最小复现作为方向可行性硬门，不提前宣称实验结论。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **建立三信号证据表**
   - 记录候选方向、目标任务、用户的时间/资源约束和检索日期。
   - 分别核对近两三年文献活跃度、综述覆盖、组内真实传承；每个信号写明来源、强弱判断和证据状态（已确认、部分支持、缺失或待核验）。
   - **完成标准**：每个候选方向都有三信号记录和来源，且没有把“热门”“有人做过”直接写成可行结论。
   - **STOP/待核验**：方向只有口号、没有可定义的任务或可查来源时停止评分，标记为“待核验”，要求先补问题定义或材料。

2. **建立资源硬门与基础缺口地图**
   - 将缺口分到通用理论、专业理论、实验技能、数据与设备四类，并为每一项写出具体补齐动作和验收物。
   - 逐项核对数据授权与隐私、版本和预处理、任务匹配、代码/基准可得性、设备/算力、组内交接意愿与支持方式；公共/私有只表示获取形态，不代替许可与复现核验。
   - **完成标准**：每个硬门均标为通过、条件通过、失败或待核验；至少定义一个最小合法复现任务及其成功标准。
   - **STOP/回退**：关键数据无授权、任务分布不匹配、设备/算力在承诺窗口内不可得，或不存在可运行的最小复现入口时，不得进入正式研究承诺；回退到候选方向重画或重新澄清目标。

3. **执行最小复现并给出条件性决策**
   - 在预先约定的短周期内运行最小任务，记录环境、数据版本、代码版本、命令、指标、错误、成本和未完成项；不以课程案例或论文报告值替代本地运行。
   - 输出 u02 契约：三信号评分、资源硬门、基础缺口地图、最小复现结果，以及“继续 / 限时试点 / 缩题 / 换题”的条件。
   - **完成标准**：复现有运行记录或明确阻断证据，结果能对应预设成功标准；每个继续条件和退出条件都可被下一次检查。
   - **STOP/待核验/回退**：任一关键硬门失败或限时窗口到期仍无法运行，停止把该方向写成可行；若只有综述或传承信号缺失但开源基准和社区证据可核对，则降级为“限时试点”，而不是机械否决；若目标、资源或问题发生变化，回到步骤 1 重算。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户尚未明确研究目标或候选方向，只是在导师、毕业、就业或深造之间排序；先做 `u01` 的目标与硬约束澄清。
- 用户已经锁定一篇或多篇具体论文，需要按摘要、引言、方法和实验提取组件；这属于 `u04`，不是方向可行性判断。
- 用户已有明确基线、模块或 A+B+C 方案，正在做正式复现、数据流接入、对比、消融、方差或归因；转交 `u06`、`u07` 或 `u08`。
- 用户问的是当前学校培养方案、期刊规则、就业统计、招生政策或许可证结论；本 skill 只能列出待核验项，不能替代当前官方来源和专业意见。

### 作者/课程警告的对应反例与失败模式

- `ce02`“选择超出资源承载能力的宏大方向”：设备、数据、工程或理论门槛超过现有承载力时，题目可能停留在口号层面；该候选引文为 ASR 待音频复核。
- `ce03`“定方向后不补齐理论与实验基础”：只记住主题或模型名称，却不能解释前提、运行实验或核验指标，会把组合研究退化成文字拼装；该候选引文为 ASR 待音频复核。
- `c02`“师兄师姐不愿交接仍继续追问”：课题组名义上的历史不能替代真实传承，课程未提供后续结果，不能把它写成方向必败的证明。
- 补充 `sp05`、`sg11`、`sg12` 的资源边界：原文中“公共数据集”包含经验性“大家都能用、随便用”的表述，但公共数据仍需核对许可证、隐私、版本、偏差、任务匹配和预处理；私有数据也不自动更有效或更有创新，可能带来授权、成本和复现风险。
- 补充 `sc06` 的跨领域路线：提出 Fluent、机器学习和 Python 只证明有一个候选构想；没有实验、数据和结果复核时，不能把“能做出结果”当作成功案例。

### 阶段 0 的批判边界

- **时代局限**：材料横跨 2022–2026 年，关于“近年模型”、开放资源、分区、就业、申博和培养要求的判断会随年份、学校、学科、地区和机构变化；执行时必须记录检索日期并回到当前一手规则。
- **立场边界**：材料主要来自中国大陆研究生、理工科/计算机/AI 和讲者个人经验，不能直接代表文科、医学、实验科学、艺术、海外培养体系或所有导师关系。
- **未证明假设**：成熟文献生态、A+B+C 组合或往届传承都不保证可发表、可毕业或有原创贡献；“能运行”也不等于公平比较、机制成立或合规。
- **最强反对意见**：以毕业可达性和资源承载力为起点，可能把研究训练压缩成寻找可运行组件，压低高风险探索、问题价值与长期能力建设；因此三信号必须允许限时试点，不得把成熟方向偏好写成唯一道路。
- **来源质量边界**：既有视频候选的 ASR 尚待音频复核，Documents 补充文本有导出/OCR 质量标记；专名、数字、反讽、许可和政策结论不能脱离原始来源升级。

### 容易混淆的邻近方法论

- **目标管理 vs 方向可行性**：先问“我要完成什么、硬约束是什么”是 `u01`；再问“这个候选方向的知识生态和资源能否承载”才是本 skill。
- **论文阅读 vs 方向筛选**：`u04` 解决“这篇论文由什么组成、能否复现哪些部件”；本 skill 解决“是否值得进入这个方向以及先补什么”。
- **最小复现 vs 正式实验**：本 skill 的复现只用于决定方向继续/试点/退出；`u06` 和 `u08` 才负责正式基线身份、对比、消融、方差、成本和归因。
- **导师资源 vs 传承信号**：导师或课题组“有这个方向”不等于师兄师姐愿意交接，也不等于代码、数据和设备真的可用；必须分开记账。
