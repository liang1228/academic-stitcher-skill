# Route: nature-polish

Use when the user supplies prose and asks for structural editing, academic tone, concision, Chinese-English rewriting, or Nature-style clarity while preserving scientific meaning.

“Nature-style” means concise, reader-oriented, evidence-calibrated prose. It does not authorize invented significance, novelty, mechanisms, applications, or citations.

## Diagnosis Order

1. paper-type logic;
2. section job;
3. paragraph order and one-job discipline;
4. claim/evidence/boundary alignment;
5. terminology and source fidelity;
6. sentence clarity and style.

## Claim Calibration

- Direct controlled evidence: `show`, `demonstrate`, `estimate` as appropriate.
- Indirect or correlational evidence: `suggest`, `indicate`, `is consistent with`.
- Untested mechanism: `may`, `could`, `hypothesize`.
- Prediction only: `predict`, `is expected under`.

Remove or bound unsupported absolutes such as “first”, “unique”, “unprecedented”, “complete”, “always”, and “solves”. Preserve material limitations and counterevidence in visible, logically appropriate locations.

## Translation

- Preserve meaning, evidence state, terminology, units, and citation placement.
- Translate rhetorical function rather than idioms word-for-word.
- Do not use cross-language rewriting to conceal copying or evade similarity checks.
- If the source sentence is scientifically ambiguous, flag it instead of making the translation more specific.

## Contract

Use the `nature-polish` headings from `static/core/output-format.md`. The `Change Log` must distinguish structural, claim-strength, terminology, and sentence-level changes.
