# Section: title

## Job

Signal the research object, main move or finding, and scope without overstating novelty.

## Build

1. Extract the task/object and setting.
2. Add the method, mechanism, or finding only if central.
3. Add a boundary when the evidence is population-, dataset-, domain-, or condition-specific.
4. Compare with the target venue's current naming conventions.

## Checks

- No unsupported “novel”, “universal”, “complete”, “first”, or “general-purpose”.
- A renamed inherited module is not presented as new merely because its label changed.
- The title does not mimic one source so closely that lineage is obscured.
- The scope matches the actual evidence and requested document type.

Return 3–5 variants only when useful, with a one-line trade-off for each.
